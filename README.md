# Meet Voice

**Повна покрокова інструкція:** [INSTALL.md](INSTALL.md). Потрібні і локальна програма з цього репозиторію, і розширення Firefox.

Окремий застосунок для Arch Linux / Ryoku + Hyprland і Firefox. Записує звук поточного аудіовиходу, передає WAV у вибраний вебчат Gemini або розпізнаний локально текст у Claude й показує відповідь на поточному моніторі по центру, шрифтом 14 px. API-ключ не потрібний. Модель і правила відповідей задає користувач у чаті; програма їх не змінює.

## Керування

- **Super + Alt + V** — увімкнути/вимкнути клавіші Meet Voice.
- **→** — почати запис; наступне натискання завершує й надсилає його.
- **Правий Alt + →** під час запису — завершити й надіслати аудіо разом зі скриншотом поточного монітора.
- Якщо правий Alt + → натиснуто без активного запису, починається запис із прапорцем додавання скриншота під час завершення.
- **←** — скасувати запис або очікування відповіді та прибрати оверлей. Уже відправлене повідомлення залишається в чаті.
- **×** у вікні — закрити відповідь.
- Кнопка «Скасувати запис / запит» у панелі розширення або вимкнення через Super+Alt+V скасовує локальне очікування й запис.

У вимкненому режимі стрілки вліво та вправо працюють звичайно. У ввімкненому → та правий Alt + → спрацьовують при натисканні; ← — при відпусканні. Для скриншота затисніть саме правий Alt, потім натисніть →. Лівий Alt не запускає надсилання. AltGr підтримується для розкладок, у яких правий Alt має це призначення. Порядок відпускання клавіш не впливає на надсилання. Стан клавіш зберігається через Ryoku Hub; після зміни конфігурація перезавантажується. Інші прив’язки не змінюються. Максимальна тривалість одного запису — 3 хвилини; після цього запис автоматично надсилається. Під час очікування відповіді новий запис не починається.

## Трансляція без оверлею

На цій системі перевірено два різні режими:

| Джерело трансляції | Результат |
|---|---|
| **Workspaces / Робочі столи** у штатному діалозі Hyprland | Передається весь вибраний робочий стіл; захищений оверлей виключається без чорного прямокутника. |
| **Monitors / eDP-1 / HDMI…** | Текст не видно, але на місці оверлею з’являється чорний прямокутник. |

Для Google Meet вибирайте джерело через системний портал, вкладку **Workspaces**, потім потрібний стіл. Це весь робочий стіл із вікнами, а не окреме вікно. Джерело прив’язане до вибраного стола; воно не переходить автоматично на інший стіл разом із користувачем. Перед реальною трансляцією перевірте її вигляд у тестовому дзвінку/на другому клієнті. Звичайний вибір монітора не відповідає вимозі повної відсутності прямокутника.

Використовується окремий шар `meet-voice-private` і правило в користувацькому `~/.config/hypr/user.lua`:

```lua
hl.layer_rule({
    name = "meet-voice-private",
    match = { namespace = "^meet-voice-private$" },
    no_screen_share = true,
})
```

Для фонового Gemini потрібно відповідне правило `render_unfocused` для вікна Firefox на столі 9. На поточній машині це вже налаштовано для Gemini. Підтримка Workspaces потребує Hyprland і порталу з відповідним протоколом. Перевірено на встановлених Hyprland 0.57.1 та xdg-desktop-portal-hyprland 1.5.0 через реальний потік PipeWire з типом джерела 4. У порівнянні локальних кадрів центр із захищеним оверлеєм не змінився; чорного прямокутника не було.

У Ryoku для підтримки Workspaces увімкнено штатний діалог Hyprland через користувацьку накладку `~/.config/ryoku/user_edits/hypr/xdph.conf`: `custom_picker_binary = hyprland-share-picker`. Вихідний файл належить Ryoku; не редагуйте його напряму. Для повернення початкового вигляду можна змінити накладку на `hyprland-preview-share-picker` і застосувати її через `ryoku materialize`; перезапуск порталу слід робити без активних трансляцій.

## Встановлення й підключення

Залежності: `python`, `python-pillow`, `firefox`, `libpulse` (parecord/pactl), `grim`, `quickshell`, Ryoku/Hyprland. Зберігайте папку програми у постійному місці.

1. Додайте правило захисту шару у власний `hypr/user.lua`, перевірте `luac -p ~/.config/hypr/user.lua`, застосуйте `ryoku wm act config.reload`.
2. У папці програми запустіть `python3 install.py` **без sudo**. Воно реєструє окремий Firefox native host `ua.meet_voice` і перемикач клавіш. Початково → вільна.
3. Firefox → `about:debugging#/runtime/this-firefox` → **Load Temporary Add-on** → файл `web/manifest.json` із цієї папки.
4. Відкрийте підготовлений чат Gemini або Claude на столі 9, виберіть потрібну модель і задайте свої правила для аудіозапитань.
5. У панелі саме **Voice Meet** натисніть **Використовувати цей чат**. Має бути лише одна вкладка цього чату. Залиште її вибраною в окремому вікні Firefox на столі 9.
6. Увімкніть клавіші через Super+Alt+V.

Після перезапуску Firefox тимчасове розширення потрібно завантажити знову. Повторна реєстрація native host не потрібна. Застосунок має власне розширення, канал і шар; Chat Dot налаштовується окремо.

## Claude з локальним Whisper base

Claude не отримує WAV: запис розпізнає багатомовна модель Whisper `base` через whisper.cpp, потім у Claude надсилається лише текст і, за бажанням, PNG. Для Gemini надалі надсилається початковий аудіофайл. Модель у вебчаті (наприклад, Haiku) обирає користувач; автоматичні інструкції не додаються.

Одноразово встановіть локальний Whisper (без sudo):

```bash
python3 setup_whisper.py
```

Потрібні `git`, `cmake`, компілятор C/C++ та доступ до GitHub/Hugging Face. Скрипт збирає зафіксовану версію whisper.cpp й перевіряє контрольну суму моделі. Готовий виконуваний файл і модель займають близько 145 МіБ у `.local-whisper/`; вихідний код і каталог збірки під час встановлення потребують додаткового місця. Цей каталог виключений із Git і ZIP програми.

Оновіть розширення через Reload, оновіть сторінку Claude, відкрийте існуючу розмову `claude.ai/chat/…` і натисніть «Використовувати цей чат». За потреби надайте Firefox доступ до claude.ai. Не залишайте свою чернетку в полі введення. Для фонового Claude потрібне правило `render_unfocused`, як для Gemini.

Розпізнавання виконується українською на CPU, 4 потоки. Модель завантажується на час кожного запиту; після завершення процесу пам’ять звільняється. ← скасовує також розпізнавання. Скриншот знімається до його початку. Перед захопленням оверлей закривається, після чого програма чекає 0,75 секунди на його зникнення з кадру, щоб захищений шар не залишав чорний прямокутник у PNG. Тимчасовий текст видаляється разом із робочим каталогом розпізнавання; у Claude залишається надісланий текст. Після вибору іншого чату під час запису запит не перенаправляється: потрібно повторити запис для нового чату.

## Звук і дані

Джерело — `@DEFAULT_MONITOR@`: звук, який відтворюється через поточний вихід. Мікрофон не захоплюється. Якщо одночасно з Meet грає музика або інші звуки, вони також потраплять у запис; для питання викладача вимкніть інші джерела звуку.

Тимчасові WAV-файли мають права 600 у приватному каталозі `$XDG_RUNTIME_DIR/meet-voice` і видаляються після завершення або скасування. Записи, які вже надіслані Gemini, залишаються в історії вибраного чату. Скасування не видаляє вже відправлені повідомлення. Немає автоматичних фонових записів: вони починаються лише командою користувача.

Відповіді й стани показуються тим самим захищеним оверлеєм, без системних сповіщень. Час відповіді залежить від вебсервісу, обраної моделі, тривалості запису та поточних лімітів.

## Діагностика та вимкнення

```bash
python3 meet_voice.py status
python3 meet_voice.py diagnose
python3 meet_voice.py cancel
python3 hotkeys.py status
python3 hotkeys.py disable
```

Діагностика може містити останню відповідь вибраного чату. Для видалення прив’язок: `python3 hotkeys.py --remove`. Потім приберіть розширення Firefox, правило `meet-voice-private` та native manifest `~/.mozilla/native-messaging-hosts/ua.meet_voice.json`, перевіривши, що він посилається саме на цю папку.

## Перевірки

```bash
python3 tests/test_voice.py
python3 tests/test_transcribe.py
node tests/test_gemini.cjs
node tests/test_claude.cjs
node tests/test_background.cjs
```

Користувач підтвердив живу пробу українського питання → Whisper base → Claude Haiku → відповідь в оверлеї. Перевірено локальний запис WAV, передавання аудіо, аудіо зі скриншотом, повернення відповіді Gemini й користувацьке натискання → та правий Alt+→. Виключення оверлею перевірено окремим локальним потоком системного порталу для workspace. Під час початкової проби звичайного монітора виявлено чорний прямокутник — цей режим для непомітного показу не використовуйте.

Довідка: [правила шарів Hyprland](https://wiki.hypr.land/configuring/core/rules/layer-rules/), [передавання файлів у Gemini Apps](https://support.google.com/gemini/answer/14903178).

## Постійне розширення Firefox

Звичайний Firefox потребує підпису Mozilla для постійного встановлення. Пакет для приватного підписання створюється командою:

```bash
python3 package_extension.py
```

На https://addons.mozilla.org/developers/addon/submit/distribution оберіть **On your own / self-distribution**, завантажте створений `voice-meet-…-unsigned.zip` та завершіть підписання. Це не публікує розширення в каталозі AMO. Політика обробки даних: `PRIVACY.md`. Пакет містить тільки розширення, без Whisper, аудіо, скриншотів і особистого URL чату.

Після отримання підписаного `.xpi` у Firefox відкрийте `about:addons` → шестерня → **Install Add-on From File / Встановити додаток із файлу** та виберіть XPI. Якщо тимчасова копія заважає встановленню з тим самим ID, спочатку приберіть її в `about:debugging`; після встановлення виберіть чат знову. Постійна версія зберігається після перезапуску Firefox. Native host і Whisper повторно встановлювати не потрібно. Зміни в локальній папці `web/` не змінюють вже встановлений XPI: для оновлення потрібна нова версія пакета та новий підпис.


## Підписане розширення

Готові підписані Mozilla XPI доступні в [GitHub Releases](https://github.com/CEOofFameIndustry/overlay/releases). Встановіть файл `voice-meet-0.2.4.xpi` через Firefox → `about:addons` → шестерня → «Встановити додаток із файлу». Локальна програма з цього репозиторію також потрібна.

Починаючи з Voice Meet 0.2.4 використовується новий ID `voice-meet@ceooffameindustry.local.invalid`. На вже встановленій старій копії повторно виконайте `python3 install.py` з тієї самої папки, щоб оновити дозволені ID native host. Вимкніть старе розширення Meet Voice та виберіть чат у новому Voice Meet заново.
