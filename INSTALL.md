# Meet Voice: встановлення крок за кроком

## 1. Що потрібно встановити

Програма складається з двох обов’язкових частин:

- Локальна програма з цього GitHub-репозиторію: записує звук, робить скриншот, запускає Whisper і показує відповідь.
- Розширення Firefox: надсилає дані в обраний вебчат і повертає відповідь локальній програмі.

Whisper base потрібен додатково для Claude. Для Gemini Whisper не потрібен. API-ключі не потрібні: використовується ваш акаунт у вебчаті та його ліміти.

Ця версія розрахована на **Arch Linux з Ryoku + Hyprland і звичайним Firefox**. Самого Arch з Hyprland недостатньо: скрипти клавіш і визначення монітора використовують `ryoku` та `ryoku-hub`. Для інших середовищ потрібна адаптація. Firefox має бути версії 140 або новішим. Команди нижче сумісні з bash і fish.

## 2. Встановіть залежності

У терміналі:

```sh
sudo pacman -Syu --needed git python python-pillow firefox libpulse grim quickshell lua cmake base-devel
```

Ryoku має бути вже встановлений і запущений з Hyprland. Перевірте:

```sh
ryoku wm status
ryoku-hub desktop get
```

Якщо `ryoku` або `ryoku-hub` не знайдені, ця інструкція для поточної версії програми не підійде. `parecord` і `pactl` постачає libpulse; використовується поточний аудіовихід системи, зокрема через сумісність PipeWire з PulseAudio. Не встановлюйте й не перемикайте аудіосервер заради програми, якщо звук уже працює.

## 3. Завантажте програму в постійну папку

Для нового встановлення:

```sh
mkdir -p ~/Applications
cd ~/Applications
git clone https://github.com/CEOofFameIndustry/overlay.git meet-voice
cd meet-voice
```

Надалі не переміщуйте папку: Firefox native host та комбінації клавіш використовують її абсолютний шлях. Якщо програма вже встановлена в іншому місці, оновлюйте саме ту копію; другу реєструвати не потрібно.

## 4. Налаштуйте оверлей і фоновий Firefox

На вже налаштованому ноутбуці автора цей крок повторювати не потрібно.

Клавіші можна переглянути в **Ryoku Hub → Keybinds** (Super + кома). Для правил нижче використовується власний файл Hyprland. Спершу перевірте його власника:

```sh
ryoku owner ~/.config/hypr/user.lua
```

У власний `~/.config/hypr/user.lua` додайте наведені блоки лише якщо таких правил ще немає:

```lua
hl.layer_rule({
    name = "meet-voice-private",
    match = { namespace = "^meet-voice-private$" },
    no_screen_share = true,
})

hl.window_rule({
    name = "meet-voice-firefox-background",
    match = { class = "^firefox$" },
    render_unfocused = true,
})
```

Це синтаксис Ryoku з Hyprland Lua, перевірений у поточному середовищі. Друге правило дозволяє всім вікнам Firefox відмальовуватися у фоні, зокрема на столі 9; це може збільшити споживання ресурсів браузером. Якщо вже є відповідне правило для потрібного вікна, дублювати його не треба.

Перевірте та застосуйте:

```sh
luac -p ~/.config/hypr/user.lua
ryoku wm act config.reload
```

Якщо перевірка Lua виводить помилку, виправте файл перед перезавантаженням конфігурації.

## 5. Зареєструйте локальну програму

У папці Meet Voice, **без sudo**:

```sh
python3 install.py
```

Скрипт реєструє `ua.meet_voice` у `~/.mozilla/native-messaging-hosts/ua.meet_voice.json` і додає перемикач Super + Alt + V. Firefox сам запускатиме локальну програму при підключенні розширення: окремий термінал тримати відкритим не потрібно.

Якщо з’явилося «Інша копія Meet Voice вже зареєстрована», використайте папку, показану в повідомленні. Не запускайте встановлення з нової папки поверх чинної копії навмання.

## 6. Встановіть Whisper base для Claude

Пропустіть цей крок, якщо користуєтеся лише Gemini.

```sh
python3 setup_whisper.py
```

Скрипт завантажить офіційний код whisper.cpp, збере його й завантажить багатомовну модель `base`. Потрібен інтернет; початкове встановлення може тривати кілька хвилин. Виконуваний файл і модель займають близько 145 МіБ у `.local-whisper/`; початкові вихідні файли та збірка потребують додаткового місця.

Whisper розпізнає українську локально. Він запускається лише після завершення запису для Claude та завершується до надсилання тексту в чат, звільняючи пам’ять процесу. У локальній пробі пік був близько 285 МіБ RAM; для іншого запису значення може відрізнятися. Для Gemini Whisper не запускається.

## 7. Встановіть розширення Firefox

### Постійне встановлення

Отримайте **підписаний Mozilla файл `.xpi`** від автора або підпишіть пакет самі, як описано нижче. Звичайний непідписаний ZIP не встановлюється постійно у звичайний Firefox.

1. Якщо тимчасова копія вже завантажена, відкрийте `about:debugging#/runtime/this-firefox` та приберіть саме Meet Voice. Після перевстановлення може знадобитися знову вибрати чат.
2. Відкрийте `about:addons`.
3. Натисніть шестерню → **Install Add-on From File / Встановити додаток із файлу**.
4. Оберіть підписаний `.xpi` й підтвердьте встановлення та потрібні дозволи.
5. Закріпіть Meet Voice на панелі Firefox через меню розширень (значок пазла).

Розширення залишатиметься встановленим після перезапуску Firefox.

### Якщо підписаного XPI ще немає

Тимчасово: `about:debugging#/runtime/this-firefox` → **Load Temporary Add-on** → виберіть `web/manifest.json` у папці програми. Після перезапуску Firefox цю дію треба повторити.

### Як автору отримати підписаний XPI

```sh
python3 package_extension.py
```

Скрипт надрукує шлях до `meet-voice-ВЕРСІЯ-unsigned.zip` у батьківській папці.

1. Увійдіть на https://addons.mozilla.org/developers/addon/submit/distribution.
2. Для приватного поширення оберіть **On your own / self-distribution**. Для публічного каталогу — відповідний публічний варіант.
3. Завантажте згенерований ZIP і заповніть обов’язкові поля. Правила обробки даних є у `PRIVACY.md`.
4. На питання про мініфікований/згенерований код оберіть **No**: JavaScript у пакеті читабельний і не потребує збірки.
5. Завершіть процес Mozilla, дочекайтеся доступності підписаного пакета та завантажте `.xpi`.
6. Встановіть `.xpi` за інструкцією вище. Сам факт завантаження ZIP на Mozilla ще не означає, що підписаний XPI вже видано.

Кінцевому користувачу не потрібно самому підписувати розширення, якщо автор уже надав підписаний XPI.

## 8. Виберіть чат на столі 9

1. У Firefox відкрийте Gemini або Claude та увійдіть у свій акаунт.
2. Створіть окрему розмову. Оберіть модель у самому чаті й задайте свої правила відповідей. Розширення їх не додає.
3. Надішліть початкове повідомлення й дочекайтеся відповіді, щоб розмова отримала постійну адресу (`gemini.google.com/…/app/…` або `claude.ai/chat/…`).
4. Залиште лише одну вкладку цієї адреси. Поле повідомлення має бути порожнім, без старих вкладень.
5. Відкрийте панель **Meet Voice — Gemini / Claude**, натиснувши значок на панелі Firefox, і натисніть **Використовувати цей чат**.
6. Перевірте, що панель показує правильну адресу й підключення до локальної програми.
7. Залиште цей чат вибраним в окремому вікні Firefox на столі 9. На поточному робочому столі відкрийте потрібний матеріал.

## 9. Користування

| Комбінація | Дія |
|---|---|
| Super + Alt + V | Увімкнути / вимкнути перехоплення клавіш |
| → | Почати запис; повторне натискання — завершити й надіслати |
| **Правий Alt + →** | Під час запису завершити й надіслати **зі скриншотом** |
| ← | Скасувати запис/очікування/Whisper і прибрати відповідь |

Комбінація зі скриншотом — саме **Правий Alt + →** (`Alt_R + Right`). Лівий Alt не запускає надсилання. Затисніть правий Alt перед натисканням стрілки. Для розкладок з AltGr також збережена відповідна прив’язка правого Alt.

Якщо правий Alt + → натиснути без активного запису, запис почнеться з позначкою додавання скриншота; наступне → завершить його. Максимальна тривалість запису — 3 хвилини.

Записується **системний звук аудіовиходу**, а не мікрофон. Для перевірки увімкніть українське мовлення у відео або Meet. Вимкніть музику та інші звуки. Натисніть → перед питанням, потім → або правий Alt + → після питання. Скриншот робиться з поточного монітора в момент завершення: на екрані має бути потрібний матеріал, а не сам чат.

Перед скриншотом оверлей прибирається з паузою 0,75 секунди, щоб чорний прямокутник не потрапляв у файл. Відповідь з’являється по центру поточного монітора, шрифтом 14 px. Для Claude передається текст від Whisper і необов’язковий PNG; для Gemini — WAV і необов’язковий PNG.

## 10. Що відбувається після перезапуску

- Підписане розширення залишається встановленим; тимчасове потрібно завантажити знову.
- Native host і Whisper повторно встановлювати не потрібно.
- Відкрийте вибраний чат, перевірте адресу в панелі Meet Voice. За потреби виберіть чат знову.
- Стан клавіш зберігається Ryoku Hub; якщо → працює звичайно, увімкніть Meet Voice через Super + Alt + V.
- Не треба вручну запускати програму в терміналі.

## 11. Оновлення

У вже зареєстрованій папці програми:

```sh
git pull --ff-only
```

Якщо Git повідомляє про локальні зміни, не використовуйте примусове скидання: спершу збережіть/узгодьте свої зміни. `setup_whisper.py` повторно потрібен лише коли модель/виконуваний файл відсутні або цього вимагає оновлення.

Для тимчасового розширення натисніть Reload у `about:debugging`. Для постійного розширення встановіть новий підписаний XPI з вищою версією: `git pull` сам не оновлює код усередині встановленого XPI. Після оновлення локальної Python-програми потрібно перезапустити її підключення: перезапустіть Firefox або вимкніть/увімкніть розширення в `about:addons`. Оновіть сторінку вибраного чату й перевірте підключення.

## 12. Перевірка проблем

У папці програми:

```sh
python3 meet_voice.py status
python3 meet_voice.py diagnose
python3 hotkeys.py status
```

- Немає підключення: перевірте, що встановлена саме Meet Voice, виконано `install.py` і вибрано чат.
- «Whisper base не встановлено»: виконайте `python3 setup_whisper.py`.
- Не бачить чат: залиште одну вкладку вибраної розмови та знову натисніть «Використовувати цей чат».
- Текст є, але надсилання не починається: приберіть свою чернетку та залишені старі вкладення перед новим запитом.
- Whisper розпізнав `[музика]`: у системному звуці була музика або недостатньо мовлення.
- Діагностика містить адресу та частину останньої відповіді: перегляньте її перед публікацією.

## 13. Трансляція екрана

Виправлення чорного прямокутника в **скриншоті для чату** не означає його відсутності в **живій трансляції монітора**. У перевіреному середовищі захоплення монітора все ще може показувати чорний прямокутник під час видимого оверлею. Режим системного порталу **Workspaces / Робочі столи** виключав захищений шар без прямокутника; він прив’язаний до вибраного робочого столу. Докладніше — у README. Перевіряйте вигляд трансляції на іншому клієнті, перш ніж покладатися на цей режим.
